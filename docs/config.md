# Configuration Guide

## General Options
- `viscosity` (number): Controls fluid dampening (default: 0.96)
- `particleCount` (number): Maximum active particles per emitter (default: 200)
- `bleedRadius` (number): Maximum expansion diameter (default: 32)
## Color Configuration
Specify primary and secondary hex strings or select a built-in preset:
- `sumi`: Traditional black and slate washes
- `indigo`: Deep blue ink tones
- `vermilion`: Crimson red accents
